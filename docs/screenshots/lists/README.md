# Lists interface comparison

The before captures show commit `5806ff0`, reviewed on November 3, 2026. The after captures use the same four list titles and game covers with the new layout. The baseline ran in development (including its developer indicator); the after captures use the Playwright production build and isolated PGlite fixtures.

The after captures are generated by `e2e/lists-layout.spec.ts`. That flow checks both themes at 320, 390, 768, and 1440px, keyboard dismissal and focus restoration, card navigation, reduced motion, 200% text enlargement, and a simulated 400px software-keyboard viewport. The creation flow separately checks draft retention with both available and blocked session storage, plus associated validation errors on creation and editing. Accessibility scans cover empty lists, the drawer, validation, and populated lists in both themes.

Visual inspection covered the attached desktop/mobile captures, wrapping titles, cover previews, empty cards, and optional-field guidance. VoiceOver, physical touch devices, a real mobile software keyboard, and browser-level 200% zoom were not manually tested; text enlargement and keyboard viewport behavior were tested through browser automation.
